Count the released frame as uninspected and require the ordinary discard decision. `control/chrome/extension/background.js:763`, `control/chrome/extension/background.js:1227`
2. **SHOULD-FIX — The native option-text fallback can read a protected descendant.** An ordinary select can contain a rich option with an explicit submission value and a credential-labelled editable child. Without a label attribute, `optionLabel` checks the option and then reads `option.text`, which gathers descendant text. A code held by that child can therefore reach the outline before any question. Refuse or withhold the option when computing its label would cross a protected descendant. This is a source finding. `control/chrome/extension/reader.js:162`, `control/chrome/extension/reader.js:408`, `control/chrome/extension/reader.js:429`.
