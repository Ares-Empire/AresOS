## Binding boot sequence

Initial live install and stock hardware setup use **Linux first**, including any one-time automatic reboot and offline login. In step 4's Windows/tools round trip, put **Windows Boot Manager first**, Save and Exit, and observe unattended Windows. **Step 5 repeats the no-key/no-USB Windows proof**, original-Micron EFI comparison and corrected-stock checks; record STEP 5 COMPLETE before authentication/switching. Windows stays first afterward; **F12** (or **Fn+F12**) selects one Linux start. No tools stick at firmware startup; insert only after Linux sign-in. Backup stock stays German; `ares-recovery` stays the administrator; its automatic OS updates remain off through the trial.

**Return to step 1:** [start the checklist](INSTALL.md#1-backups-recovery-and-windows-preparation). If you arrived during a trial, [Help](INSTALL-REFERENCE.md#help) returns explicitly to your recorded step; step 6 rechecks step 5 on every entry.
