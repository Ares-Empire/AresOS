# Foot icon fixture

`foot-before.png` is Lennard Hofmann's Foot logo from the installed Foot package
(`hicolor/48x48/apps/foot.png`). The AresOS app helper resized it to its usual
128 × 128 cached PNG. The icon is used under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

`gate-v2.txt` records the resulting 12 × 12 gate face from top to bottom
before package 327. A dash denotes an empty cell.
